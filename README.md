# AHAD JUS DUX Website

Premium static website for AHAD JUS DUX: India-Middle East Trade & Commercial Counsel.

## Business positioning

This version is based on the updated business plan. The website now presents AHAD JUS DUX as a boutique India-based commercial legal and trade-support practice focused on:

- Shipping and logistics documentation
- Import-export operational support
- Cross-border commercial contracts
- India market-entry support
- Intellectual property and trademark protection
- Supplier and distributor agreement structuring
- Recurring external trade operations counsel

## GitHub upload structure

Upload all files directly into the main/root area of the GitHub repository.

Your repository should look like this:

```text
README.md
index.html
style.css
script.js
logo.png
intro.mp4
```

Do not put the media files inside a `public` folder for this version.

## Required media file names

The website expects these exact file names:

```text
logo.png
intro.mp4
```

Do not rename them to names like:

```text
logo(1).png
intro-final.mp4
```

## After uploading to GitHub

1. Upload or replace `index.html`, `style.css`, `script.js`, and `README.md`.
2. Upload `logo.png` and `intro.mp4` in the same root folder.
3. Commit the changes.
4. Go to Netlify and wait for the new deploy to finish.
5. Open the website and hard refresh:
   - Windows: `Ctrl + F5`
   - Mac: `Command + Shift + R`

## Notes

The website is static HTML, CSS, and JavaScript. No build step is required.
