# AHAD JUS DUX Liquid Glass Website

This package is a premium static website redesign using an iOS-style liquid glass interface.

## Upload structure

Upload these files to the root of the GitHub repository:

```text
index.html
style.css
script.js
logo.png
intro.mp4
README.md
```

No build step is required. Netlify can deploy this as a normal static site.

## What changed

- Professional liquid glass interface with transparent panels and blurred depth
- Dark and light mode with a persistent theme toggle
- Floating iOS-style navigation bar
- Scroll progress indicator
- Smooth reveal animations with staggered card loading
- Parallax hero card movement
- Better mobile menu and responsive layout
- Retained the intro video and logo
- Retained the matter enquiry mailto form

## Optional background images

The current version uses pure CSS gradients, so it will not create missing-image errors. If you later want custom dark and light background images, add them to the root folder and update the commented background area in `style.css`.
